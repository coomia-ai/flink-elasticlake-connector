# 路线图

[English](roadmap.md) | 简体中文

路线图描述验收阶段，不承诺交付日期，也不代表功能已发布。

| 阶段 | 范围 | 验收要求 |
| --- | --- | --- |
| 工程初始化 | 独立构建、模块目录、双语文档、许可证、CI 配置 | 骨架构建可执行，不声明 runtime 能力 |
| 经评审的基础设施 | 精确 SDK 制品、隔离逻辑 API 变体、架构规则、Java 17 消费者 | 合同获批、版本及 SHA 核验、非空规则扫描、独立构建 |
| 协议与模型 | 源覆盖、身份、不可变 spool、序列化、恢复模型 | 独立字节夹具、属性及模型测试、损坏或不支持输入拒绝 |
| Flink Sink | Writer、assembler、提交 lane、checkpoint 及恢复接入 | 真实 Flink 1.20.3 拓扑、abort、有界 drain、重分片及类加载验证 |
| 可选 S3 恢复 | 不可变对象、条件控制更新、库存及保留 | 真实 S3 故障、CAS、分页及受控 run 验证 |
| 端到端发布 | 真实 SDK / 服务端写入、对账、可安装制品及报告 | 恢复与数据 oracle、资源上界、兼容及许可证评审 |

本次初始化覆盖工程骨架，不完成上游 I-06 基础验收、正式 API 评审或产品 runtime 门。
并行提交与重分片、无人值守 failover、SQL/Table 集成、Source 连接器、其他 Flink
版本及性能保证均需另行设计决策和证据；checkpoint 完成尤其不提供跨表原子可见性。
