# 发布检查

[English](releasing.md) | 简体中文

当前没有发布版本或远程发布任务，不能把骨架 JAR 作为功能性连接器分发。首次发布前：

1. 配置真实公开仓库 URL、可验证的维护者及安全联系方式、分支保护和受控制品仓库；
   同步文档及后续发布元数据，不虚构坐标或上传目标。
2. 完成 API、状态格式、恢复及 runtime 审批；分别验证真实 SDK、服务端、Flink 行为
   和支持的部署 profile。
3. 使用干净源码基线、Wrapper、经评审的版本目录及依赖锁、准确 SDK 清单，并在
   JDK 17 实际构建运行；Java 21 架构规则单独执行，保留实际报告。
4. 准备不可覆写的发布版本、发布元数据、源码、Javadoc、LICENSE/NOTICE、第三方
   声明及 SHA-256 清单；评审依赖许可证和 SBOM，发布前审核签名及仓库凭据。
5. 检查制品不包含 Flink runtime、数据库内部实现、测试规则、密钥、重复逻辑 API 类
   或未批准 provider 依赖；在干净 Flink runtime 安装并验证 classloader 身份。
6. 更新双语文档、兼容实证、安全支持政策、changelog 及升级恢复说明，明确不支持项。
7. 由受影响 owner 评审准确发布输入及结果，再按已配置流程发布，最后验证下载到的
   制品和校验和。

发布制品、创建 release tag 和对外公告均独立于本地工程初始化；CI 通过不等于发布门通过。
